# AINewsCrawler

Um **web crawler** desenvolvido em Python para coletar notícias sobre inteligência artificial de fontes como **Google News** e **Bing News**.

## Funcionalidades

- Pesquisa notícias relacionadas à Inteligência Artificial e termos associados.
- Coleta artigos de Google News e Bing News.
- Salva os resultados em um arquivo CSV.
- Remove duplicatas com base no título da notícia.
- Gera um resumo das fontes coletadas.
